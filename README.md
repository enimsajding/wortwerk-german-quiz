# Wortwerk

An interactive German practice quiz spanning A1–C2, with separate beginner, intermediate and advanced tracks covering vocabulary, grammar, idioms, register and natural expression.

## Run locally

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

The static site is generated in `dist/`. The included GitHub Actions workflow deploys it to GitHub Pages whenever `main` is updated.
